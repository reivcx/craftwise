About Craftwise

Craftwise is a fan-made static HTML/CSS guide website. Every guide is a separate HTML file and every navigation link uses a real relative href.

Version note: Minecraft mechanics can change between releases and between Java and Bedrock Edition. Check your exact version before relying on version-sensitive farms, villager mechanics or redstone designs.

Guide information was cross-checked with official Minecraft resources, especially the official beginner guide and Minecraft Help's enchantment reference.
